# סולם — שאלון ערכים לבחירות 2026

הדף שמוגש לגולשים. הקוד, השאלות והתיוג נמצאים בתיקיית העבודה בדרייב.

| קובץ | מה זה |
|---|---|
| `index.html` | השאלון כולו בקובץ אחד — נבנה מ-`app/index.html` על ידי `build_bundle.py` |
| `config.js` | כתובת ה-Web app של Apps Script. השורה היחידה שמשתנה בין סביבות |
| `.nojekyll` | מבקש מ-GitHub Pages להגיש את הקבצים כמו שהם |

## לעדכן את השאלון
1. לערוך ב-`app/` (שאלות ב-`01-…07-*.md`, ואז `build_questions.py`)
2. `python3 build_bundle.py`
3. לבנות מחדש את התיקייה הזאת ולדחוף

## מה לא נמצא כאן
השמירה, הניתוח המילולי ומייל האחזור רצים ב-Google Apps Script שצמוד לגיליון,
ולא בריפו הזה. `config.js` הוא מה שמחבר ביניהם.
